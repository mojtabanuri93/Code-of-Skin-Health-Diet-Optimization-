# Code-of-Skin-Health-Diet-Optimization-
This repository contains the complete code and data used in the paper "A Lexicographic based Approach to Skin-Health Diet Optimization Problem under Epistemic Uncertainty" to ensure full reproducibility.

guide for the code:

GP: Goal Programming,
WS: Weighted Sum,
LP: LP-metric approach,
LLP: Lexicographic LP-metric approach,

Female and Male are gender of people for case study,
Fuzzy is the logic of uncertainty,

less 0.5: the confidence levels are less than 0.5 (or 50%),
more 0.5: the confidence levels are more than 0.5 (or 50%).
